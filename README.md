# Agrinho 2026 - IA e Sustentabilidade no Campo

Uma página web responsiva desenvolvida para o Projeto Agrinho, com foco na categoria **Agricultura Sustentável e Tecnologia**. O site apresenta de forma clara e visual como a Inteligência Artificial e o Sistema de Plantio Direto (SPD) atuam juntos na descarbonização e na eficiência do agronegócio.

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estrutura semântica das seções e conteúdos.
* **CSS3 (style.css):** Estilização, layout responsivo e transições.
* **JavaScript (script.js):** Menu hambúrguer interativo para dispositivos móveis.
* **Imagens:** Integração com o Unsplash para ilustrações de alta qualidade.

## 📋 Funcionalidades e Seções

* **Menu Responsivo:** Navegação adaptável com menu hambúrguer para telas menores.
* **Início (Hero):** Introdução impactante sobre a nova era agrícola.
* **IA & Previsão:** Detalhes de como o *Machine Learning* prevê microclimas e otimiza o manejo.
* **Plantio Direto:** Vantagens práticas do uso da palhada na proteção do solo.
* **Carbono no Campo:** Explicação do impacto ecológico e do sequestro de CO₂.

## 📂 Estrutura do Projeto

```text
├── index.html      # Estrutura principal da página (HTML)
├── style.css       # Estilização e responsividade (CSS)
└── script.js       # Comportamento do menu hambúrguer (JS)
```

## 🛠️ Como Executar o Projeto

1. Faça o clone ou baixe os arquivos deste repositório.
2. Certifique-se de que os arquivos `index.html`, `style.css` e `script.js` estão na mesma pasta.
3. Abra o arquivo `index.html` em qualquer navegador web moderno.
