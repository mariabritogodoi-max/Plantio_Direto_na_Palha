HTML (index.html)
O HTML funciona como o "esqueleto" do site.

header e .navbar: Contêm o logotipo do Agrinho e a estrutura de navegação (nav). É aqui que fica o botão .hamburger com o caractere especial &#9776; (as três barrinhas).

section (Tópicos): Cada seção usa uma classe comum (.topic-section) para manter o padrão, mas a segunda seção usa a classe .reverse. Isso serve para inverter a ordem entre imagem e texto no CSS, criando um visual alternado (Ziguezague) que deixa a leitura menos cansativa.

Semântica: Uso de tags como <header>, <section> e <footer>, o que é muito valorizado em critérios de avaliação tecnológica (SEO e acessibilidade).
